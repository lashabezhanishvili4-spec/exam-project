\# Git Command History



\## Project: Skillwill Exam Project Portal



The following Git commands were used during the completion and verification of the project.



\### 1. Check Git installation



```bash

git --version

```



\### 2. Check repository status



```bash

git status

```



\### 3. Check available branches



```bash

git branch

```



\### 4. Add GitHub repository as remote origin



```bash

git remote add origin https://github.com/lashabezhanishvili4-spec/exam-project.git

```



\### 5. Push all local branches to GitHub



```bash

git push -u origin --all

```



\### 6. Display commit history and branches



```bash

git log --oneline --all --decorate

```



\### 7. Verify the final index.html on the main branch



```bash

git show main:index.html

```
